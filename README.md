## XDRS

[<img alt="Crates.io Version" src="https://img.shields.io/crates/v/moq?style=flat-square">](https://crates.io/crates/xdrs)
[<img alt="docs.rs" src="https://img.shields.io/docsrs/xdrs?style=flat-square">](https://docs.rs/xdrs)
[<img alt="GitHub Actions Workflow Status" src="https://img.shields.io/github/actions/workflow/status/LazyMechanic/xdrs/ci.yml?branch=master&style=flat-square">](https://github.com/LazyMechanic/xdrs/actions/workflows/ci.yml)

Rust implementation of XDR [RFC 4506](https://www.rfc-editor.org/info/rfc4506) format. This library provides traits for encoding/decoding to/from binary format, derive macros and code generator from XDR schema.

```toml
[dependencies]
xdrs = "0.1"
```
